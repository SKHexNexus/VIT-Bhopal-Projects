## Student Attendance Tracker (CLI)

A lightweight Command Line Interface (CLI) application built using Python to record, evaluate, and report student attendance across multiple subjects.

### Features

- **Multi-Student Data Entry**: Input names, registration numbers, subject counts, total working days, and present days.
- **Automated Percentage & Performance Categorization**:
  - `>= 90%`: Excellent - Keep Going
  - `80% - 89.9%`: Good - Try to Improve
  - `75% - 79.9%`: Satisfactory - Improvement Needed
  - `< 75%`: Critical - Attend Classes Strictly
- **Report Views**:
  - View full attendance reports for all enrolled students.
  - Search and view report for a specific student using their Registration Number.
- **Input Validation**: Ensures present days do not exceed total working days.
